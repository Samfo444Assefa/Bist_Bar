# Ethiopia Tourism — Land of Origins

Cinematic React + Vite + Tailwind tourism homepage.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/components/` — homepage sections
- `public/images/` — place local tourism images here
- `src/App.jsx` — application shell
- `src/index.css` — global styles
- `vite.config.js` — Vite + Tailwind plugin
